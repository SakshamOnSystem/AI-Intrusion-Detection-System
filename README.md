# AI Intrusion Detection System

## Overview
An AI-based intrusion detection system designed to identify potentially malicious network activity using machine learning.

## Features
- Machine-learning-based intrusion detection
- CIC-IDS2017 dataset support
- Real-time detection component
- Python-based implementation

## Technologies
- Python
- Machine Learning
- CIC-IDS2017 dataset

## Project Structure
- `ai_ids_cic2017.py` — Dataset/model processing
- `app_live.py` — Application interface
- `realtime_ai_ids_cic2017.py` — Real-time detection component
- `models/` — Model files
- `requirement.txt` — Dependencies

## Installation

Clone the repository:

    git clone https://github.com/SakshamOnSystem/AI-Intrusion-Detection-System.git

Enter the directory:

    cd AI-Intrusion-Detection-System

Install dependencies:

    pip install -r requirement.txt

## Usage
Review the scripts and their configuration before running the application.
